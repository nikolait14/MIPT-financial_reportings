# Локальный baseline распознавания строки КФЗ

PoC рендерит первую страницу КФЗ в 300, 400 и 600 DPI, запускает локальный Apple Vision OCR, находит строку `3 этап, 2026 г.`, определяет границы ее ячеек и проверяет каждое значение по отдельности.

Данные не передаются во внешние сервисы.

## Запуск

```bash
bash poc/kfz-row-extraction/run_local_baseline.sh \
  data/case-19/all/01_Карточка_учета_фактических_затрат_этап_3.pdf \
  artifacts/kfz-row-extraction
```

Apple Vision на этой машине требует запуск вне ограниченного sandbox процесса. Исходный PDF должен быть предварительно помещен в `data/case-19`.

## Результаты

Для каждого DPI создаются:

- исходный рендер страницы;
- JSON трех полностраничных OCR-прогонов;
- изображение с отмеченной целевой строкой;
- контактный лист отдельных ячеек;
- JSON трех region-first прогонов;
- индивидуальная оценка каждой ячейки в JSON и Markdown.

Средние денежные ошибки не рассчитываются. Один `MISMATCH` в критической ячейке означает `FAIL` соответствующего прогона.
