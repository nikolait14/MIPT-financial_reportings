# Задача 5. Проверка достоверности отчетности по первичным учетным документам

## Полное описание

Необходимо разработать систему, которая сопоставляет показатели итогового отчета с первичными учетными документами, на основании которых он был сформирован.

Решение должно находить расхождения в суммах, показателях и других значениях, показывать источник каждого несоответствия и формировать итоговое заключение о достоверности отчета. Пользователь должен иметь возможность понять, из какого документа получено ожидаемое значение и почему конкретная строка отчета считается корректной или ошибочной.

## Вводные данные

На вход подается набор данных, включающий итоговый отчет (КФЗ) и связанные первичные и расчетные документы в разных форматах: PDF, DOCX, XLSX, PNG, в том числе сканы.

Документы различаются по структуре и формулировкам. Связь с показателями отчета определяется по реквизитам (номер договора, период, номер документа) и содержанию. В наборе могут встречаться:

- дубли;
- документы другого периода или договора;
- показатели, для которых подтверждающих данных недостаточно.

В промышленной эксплуатации входные документы могут быть существенно сложнее для извлечения и интерпретации: низкокачественные сканы, нестандартные формы, неполные или ошибочные реквизиты, различная верстка и дополнительные форматы.

## Ожидаемый результат

На вход система получает итоговый отчет и набор связанных первичных документов. На выходе должен формироваться результат сверки, позволяющий проверить каждое найденное расхождение:

1. Статус проверки каждого показателя или строки отчета.
2. Фактическое значение из отчета и ожидаемое значение, рассчитанное или извлеченное из первичных документов.
3. Размер расхождения, если значения не совпадают.
4. Ссылка на первичный документ и конкретный фрагмент, который подтверждает ожидаемое значение.
5. Категория несоответствия, например: расхождение суммы, пропущенный документ, дублирование, неверный период или несовпадение другого показателя.
6. Итоговое заключение о достоверности отчета с краткой сводкой найденных проблем.

## Ограничения

Через любые внешние API можно передавать только открытые (неконфиденциальные) данные.
